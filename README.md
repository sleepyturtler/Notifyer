Get fast and free notifications from you favourite creators across YouTube, Twitter/X, Twitch, Kick and TikTok with Notifyer.

# Commands
## Social:
- **/social access:** Set who can access the setup commands.
- **/social add:** Track a new account,
- **/social list:** Lists all tracked accounts.
- **/social check:** Manually checks if new posts are available.
- **/social link:** Link your Tiktok/Instagram account, so you can track it's posts.
- **/social links:** View all OAuth linked accounts.
- **/social customize:** Preview a watch's notification and customize it (message, batch header, ping role, embed color, image, embed on/off), then Save.

## Other:
- **/help:** Shows all commands and other useful info.
- **/invite:** Creates an invite with all the right permissions.
- **/setup:** Introduces you to the bot and helps you set up your first watch.
